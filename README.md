# Marmoraria São Carlos

Site institucional da Marmoraria São Carlos, de Catanduva/SP.

## Páginas
- Início
- Serviços
- Sobre
- Contato
- Política de Privacidade

## Observação sobre imagens
O briefing menciona fotografias reais dos trabalhos e da fachada, mas os arquivos de imagem não estavam disponíveis na implementação. Os espaços visuais estão preparados para receber essas fotos sem alterar a estrutura do site.

## Desenvolvimento local
Projeto estático: abra `index.html` ou sirva a pasta com qualquer servidor HTTP local.
